## 🌌 The Vision
This isn't just a portfolio—it is an **Engineering Dashboard**, a **Cinematic Journey**, and a **Tactile Interface**. 
Designed not just to list projects, but to *prove* technical ability through relentless attention to detail, sub-ms performance optimization, and hardware-accelerated fluid physics.

---

## ⚡ Core Architecture

### **Frontend & Rendering Engine**
- **React.js (v18)** + **TypeScript**: Strict-typed, concurrent rendering foundation.
- **Vite CLI**: Lightning-fast unbundled ESM local hotswapping.
- **Tailwind CSS**: Zero-runtime utility classes enforcing a rigorous, mathematical design system (Base monochromatic palette `#1C1C1C` & `#F6F3EE` slashed with `#B45309` accents).

### **Physics & Motion Graphics**
- **Framer Motion**: Orchestrating complex declarative UI transitions, SVG morphs, and layout interpolations.
- **GSAP (GreenSock)**: Handling heavy scroll-linked timelines, parallax masking, and hardware-accelerated transforms.
- **Lenis Scroll**: Silky smooth, momentum-based custom scrolling physics overriding the native browser jank.

### **3D Dimension & Spatial Computing**
- **Spline WebGL Engine**: Hosting an interactive, 3D isomorphic mechanical keyboard. Click detection on individual 3D keycaps automatically triggers contextual AI explanations and UI routing logic natively in the React lifecycle.

## 🧠 The AI "Synthetic Nervous System"
At the bottom right of the screen sits **Rachit's AI Guide**—a contextual neural network directly wired into the portfolio's state.

* **Engineered with**: xAI Grok (Streaming Completion API)
* **Custom Context Window**: The AI is injected with a hyper-specific system prompt detailing all projects, tech stacks, and experiences.
* **Component Bridge**: When a user physically taps a 3D Spline Keycap (e.g., the *JavaScript* key), an event dispatcher forces the AI to open and instantly explain Rachit's expertise in JavaScript.

---

## 📱 Mobile "God-Tier" Tactility
Mobile views aren't an afterthought—they are fundamentally re-engineered architectures.

- **Categorized Pill Clouds:** The massive 3D keyboard gracefully degrades into a responsive, fluid flex-box cloud categorized by stacks (Frontend, Backend, Ops).
- **Native Haptics Integration:** Leveraging `window.navigator.vibrate`, interacting with the skills fires sub-millisecond physical pulses directly into the user's hand, mimicking mechanical keyboard switches.
- **Strict Viewport Firewalls:** Absolute `overflow-x: clip` limits ensures the DOM never fragments on smaller screens, retaining 60fps GPU-accelerated CSS transforms.

## 🚀 Setup & Local Ignition

Initiate the sequence locally:

1. **Clone the matrix:**
   ```bash
   git clone https://github.com/Rachit-Kakkad1/Rk-Portfolio.git
   cd Rk-Portfolio
   ```

2. **Install neural dependencies:**
   ```bash
   npm install
   ```

3. **Configure the Environment:**
   Create a `.env` file at the root:
   ```env
   VITE_XAI_API_KEY=your_xai_grok_key_here
   ```

4. **Launch the Engine:**
   ```bash
   npm run dev
   ```
   *The reactor goes live at `http://localhost:5173`.*
